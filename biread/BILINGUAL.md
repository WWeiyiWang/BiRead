# BiRead 使用说明

BiRead 是 Zotero 内置 PDF 阅读器的双语阅读扩展，仍处于 beta 阶段。复杂 PDF 的结构和版面识别可能出错，正式使用前请先备份 Zotero 数据并完成手动测试。

## 安装与兼容性

从 [BiRead Releases](https://github.com/WWeiyiWang/BiRead/releases) 下载 XPI，在 Zotero 中选择 **工具 → 插件 → 齿轮菜单 → 从文件安装插件…**，选中 XPI 并按提示重启。

BiRead 使用独立插件 ID 和偏好设置，不会替换上游插件或迁移其凭据。Beta 阶段不建议与上游插件同时启用。

清单声明支持 Zotero 7.9.9–10.9.9；现有开发记录中的自动化验证环境为 Zotero 9.0.6，声明范围内其他版本尚未全部验证。

## 配置翻译

BiRead 复用 Zotero 的 Translate 设置。在 Zotero 设置中选择一个句子翻译服务并按该服务的要求配置。部分服务无需 API 密钥；另一些服务需要自己的密钥、账号或本地服务。费用、可用性和隐私条款由服务提供方决定。

## 阅读

1. 在 Zotero 内打开有可选中文字的 PDF。
2. 点击阅读器工具栏里的 **BILINGUAL**。
3. 选择阅读方式：
   - **沉浸式阅读**：中英对照、仅中文或仅英文；可调字号、行距、翻译速度和术语表。
   - **PDF 对照**：原生 PDF 与可选中译文并排，保留原页大小、页眉页脚及正文、图表、表格的近似原位置。译文内容在原区域自适应，不能保证与原 PDF 逐像素相同。
4. 页面文本先提取并显示，之后按段落翻译。暂停后恢复会保留已完成译文；译文缓存在本地，重复打开可复用缓存。

图注附近的内嵌图片可以显示；某些矢量图表会按图表区域生成预览。图中像素和文字不翻译。表格只有在行列边界可可靠识别时才会重建为可翻译表格；其他表格仍需在原 PDF 中核对。

## 标注

选择文本后使用 **Highlight selection**、**Underline selection** 或鼠标旁的右键菜单。英文按 PDF 坐标保存；中文无法匹配英文时，仍保留为本机 BiRead 标注，不扩大成整句。

词组匹配在本机执行，不额外调用 Google 或远程大模型。优先使用相同文字、术语表和当前文档已确认的对应关系；可在“本地对齐模型”中选择配置 JSON，启用离线 ONNX 上下文词组匹配。点击高亮、划线或批注后自动匹配并保存，不再预览或二次确认；匹配失败保留单侧标注。模型仍可能错配或漏配，不能保证每个词自动对应。

本地模型配置包含 `python`（Python 可执行文件）、`model`（含 model.onnx、tokenizer.json 的目录）、`deps`（onnxruntime、tokenizers、numpy 安装目录）三个绝对路径。插件通过标准输入/输出调用本机 Python，不启动网络服务，也不自动下载模型。当前实测环境为 Windows、Zotero 10.0.6，模型为 cstr/awesome-align-onnx-int8，修订 e803a2f501474044099b539160aaca461976ecd0。模型约 150 MB，模型与 Python 依赖共约 295 MB，另需兼容的 Python。模型文件不包含在 XPI 中；换电脑需重新配置。

每段首次对齐启动本机进程，后续同段使用内存缓存；超过模型 512 token 长度或运行失败时保留单侧标注并提示手动绑定。确认后的两侧精确文本范围写入本机映射缓存，原 PDF 中保存英文标注坐标。关闭论文或重启 Zotero 后从磁盘恢复，不依赖模型重新猜测。旧错误标注不会被批量覆盖，请使用下面的重新关联功能修正。

已确认的词组可在当前文档的其他位置作为候选复用。旧版本未确认的猜测不会自动传播。正文翻译仍使用原先配置的翻译服务，其费用规则不变。

手动修正（同样适用于旧标注）：

1. 在沉浸式中英对照视图点击高亮，打开 **绑定 / 重新关联词组**。
2. 选中同一段的英文或中文词组，点击 **使用英文选区 / 使用中文选区**，也可右键 **用此选区重新关联**；打开标注后也可直接在另一侧选择文字，右键 **绑定到当前标注…**。两侧都可以重选。
3. 检查面板中的英文、中文预览后点击 **确认绑定**。取消不会修改标注。

绑定已有 PDF 标注会保留原标注 ID、颜色和批注；本机中文标注绑定英文后会写入原 PDF。关系在当前文档中双向复用，保存在本机，不通过 Zotero 同步。重新翻译导致文字改变时旧关联失效，需要重新选择。手绘仍使用原 PDF 的原生工具。

## 隐私与数据

翻译时，提取出的正文文本会发送到所选翻译服务；学术模式可能会连同提示词及相关术语发送。图片预览在本地读取，不作为翻译请求内容。BiRead 不运行自己的远程服务器。

提取文本、译文、术语表和映射数据保存在 Zotero 数据目录的 `biread-bilingual-v1/`。BiRead 使用独立的 `extensions.zotero.BiRead.*` 偏好设置；服务凭据留在本机，BiRead 不会读取、迁移或删除上游插件的密钥。首次使用需要在 BiRead 中重新填写服务凭据；BiRead 没有另外增加加密层。若分享日志或截图，请先删除密钥、令牌、个人路径和私人论文内容。

## 当前限制

- 扫描版 PDF 没有 OCR；页面必须有可选择文本才能翻译。
- 阅读顺序、标题层次、页眉页脚、图表及表格识别均依赖启发式规则，复杂版式可能出现错位或遗漏。
- 没有图注的矢量图、跨页图表和不规则表格可能无法自动识别。
- 词组自动对齐不能保证准确；含省略、意译、重复词时建议手动确认。
- 手机端阅读及译文 PDF 导出尚未实现。

## 开发

BiRead 是基于 [windingwind/zotero-pdf-translate 2.4.8](https://github.com/windingwind/zotero-pdf-translate) 的独立分支，保留其翻译功能，并以独立插件身份增加双语 PDF 结构提取、阅读模式、翻译缓存和映射批注工作流。用户无需另外安装上游插件。上游版权和 AGPL 许可声明保留；BiRead 不是上游的官方更新，也不代表上游维护者背书。两者可以分别安装，但 beta 阶段不建议同时启用，因为 PDF 划词弹窗和批注标题处理器仍会重复注册。BiRead 已将自定义元素、菜单和偏好命名空间独立化，但 reader hooks 仍需专项共存测试。使用 BiRead 时请停用上游插件；BiRead 不会自动修改或卸载其他插件。

在 `biread/` 目录安装依赖并运行 `npm ci`，之后可运行 `npm run typecheck`、`npm run lint:check`、`npm run test:bilingual` 和 `npm run build`。需要启动 Zotero 的集成测试请先查看 `docs/development/MANUAL_INSTALL_TEST.md`；不要把真实密钥或私人 PDF 用于自动化测试。

许可信息见仓库根目录的 [LICENSE](../LICENSE)。BiRead 新增代码的版权标注仍需人工确认。

右键菜单仅保留“高亮、划线、批注”三项，并保持所选文字可见。对应有误时，点击已有标注，在详情中打开“绑定 / 重新关联词组”；可以重选两侧文字后点击“使用选区”，或输入本段中唯一出现的对应词，再确认绑定。自写释义填写在批注中。

批注输入后自动保存，无需点击 Save comment；切换标注或关闭面板会等待保存。保存失败会显示提示并保留输入。
