# Zotero 双语阅读开发版

版本：2.4.8-bilingual.12。基于 Translate for Zotero 的服务、凭据、偏好设置、生命周期、构建和打包系统扩展。

## 安装与使用

1. 在 Zotero 的“工具 → 插件”中，选择“从文件安装插件”，打开本项目 dist 目录中的 XPI。
2. 在原有 Translate 设置里配置翻译服务与凭据。学术模式支持 ChatGPT、自定义 GPT 1–3、Azure GPT、Claude、Gemini。Google 等普通服务在勾选 ACADEMIC MODE 时也会继续普通翻译，并显示能力提示；学术润色和术语表约束只对上述大模型服务生效。
3. 正常打开可选中文字的 PDF，点击阅读器工具栏的 **BILINGUAL**。
4. 原文结构先显示，中文逐段填入。默认英文在左，占 42%；中文在右，占 58%。可以选择 50/50。
5. 选中一段内的中文或英文，点击 **Highlight selection**。选择中文时，英文批注按选区在句段中的相对位置近似映射到英文单词或短语；译序变化可能影响词级对应。
6. 点击高亮打开同一条 Zotero 批注，可修改评论、颜色或确认后删除。原生批注侧栏仍可使用。
7. **PDF** 和 **OPEN IN PDF** 返回原文所在页/位置；再次点击 BILINGUAL 返回阅读位置。
8. **Glossary** 中每行填写 `embodiment → 具身性`。选择 **Save & retranslate affected blocks** 只为相关术语发生变化的块请求新翻译。

本开发版保留原插件 ID 和偏好设置命名空间。安装会替换现有 Translate for Zotero，而不是另装一份平行翻译插件。Zotero 要求保留非空 update_url，因此安装清单保留上游地址，但开发版在启动时关闭自身自动更新，避免被上游版本覆盖。手动更新仍可能恢复为上游版本；原版也可从上游重新安装。

## 交互与数据

- 双语内容位于 Zotero PDF 视图内部的本地空白 iframe 中，隔离 PDF.js 的鼠标/键盘捕获事件；不打开外部浏览器。
- 双列采用同一行网格与同一滚动容器。内部句段 ID 用于映射，视觉上仍显示完整段落。
- 先提取整个文档的文本结构，再显示原文并逐块翻译。暂停会停止后续请求；已经发出的服务请求会自然结束，恢复时读取已完成的缓存。
- 服务错误、缺失 ID、重复 ID、被破坏的引文占位符不会作为成功翻译缓存。Retry / Resume 从已保存部分继续。请求等待时显示当前服务、页码和耗时；单次请求 90 秒超时，迟到的结果不写入缓存。底层请求由各服务管理，超时不保证取消其网络连接。
- 切换服务或模式会在当前请求结束后自动使用新设置继续；无需额外点击 Retry。
- 根据 PDF 字符尺寸、粗体和章节编号推断主标题及三级小节，合并相邻主标题行，并区分图注、列表、脚注与摘要的呈现。按原文章节归组，可通过“按章节跳转”导航；按章节内的原文段落和列表项逐段翻译。
- 结合跨页重复与页边位置过滤页眉、页脚、页码和侧边 arXiv 标记，保留脚注及其续行。不会简单裁去页面底部。正文顺序和批注坐标沿用原 PDF。
- 更新后重新打开阅读页会使用新版解析；原文和段落标识未改变的译文继续复用缓存。复杂原始版面仍为可选择文本的双栏重排，并非逐像素复制。
- 扫描页显示无可选文本提示；整个文档没有文本时显示不支持扫描 PDF。
- 图注上方显示原图或图表预览，两侧共享一张图；点击图片可放大，按钮可定位回原 PDF。原始嵌入图片直接从 PDF.js 图片对象提取；矢量图表按图注附近的图形范围渲染局部预览。公式块和参考文献保留原文。常见括号引文、数字引文、DOI、URL 和美元符号公式在大模型请求中受到不可变占位符保护；普通服务请求将这些片段留在本地，避免服务改写占位符。
- 正文仍是可选择、可批注的双语文本，没有 OCR、整页截图重建、新 PDF 导出或另外的阅读应用。按用户本次授权，仅图表区域允许渲染为预览。
- 图片按阅读位置延迟加载，与翻译队列独立；在无翻译服务或服务报错时也可以显示。预览不包含批注，不传送到翻译服务。图片数据只保留在当前阅读会话中，关闭后释放；重新打开从原 PDF 获取。
- 图表区域定位属于启发式：复杂布局、跨页图、没有图注的纯矢量图或不支持的图片对象可能无法自动显示，可用原 PDF 入口核对。

## 批注精度与已知边界

中英选区使用句段内的字符位置比例近似定位对应词语或短语，并扩展到英文词边界，避免选一个中文词却高亮整句。此方法不是语言学词语对齐，遇到中英文语序差异较大的句子可能定位不准；原文侧直接按精确字符坐标标注。本地记录选中的中英文范围；其他设备可根据 PDF 坐标及段落缓存恢复近似映射。

支持 highlight 和 underline 的原文映射；反向创建为 highlight。一次选区限制在一个段落内。重叠高亮显示多色带，点击最近一条，右键可选择其他重叠批注。批注评论直接读写 Zotero 的 annotation item，没有第二套笔记库。

Zotero 自带的字符阅读顺序用于双栏解析；标题、段落、图注与公式识别仍是启发式。复杂图表文字、不规律或仅出现一次的页眉页脚、跨页断段、脚注和数学排版仍可能需要使用 OPEN IN PDF 核对。没有对所有出版商版式作正确性保证。

## 本地存储

位于 Zotero 数据目录的 `pdf-translate-bilingual-v1/`：

- document：附件 libraryID/key、文件大小/修改时间、PDF 指纹和解析版本；保存正文块与字符锚点。
- translation：附件标识、block ID、SHA-256 原文散列、provider、model、endpoint、语言、模式、算法版本、相关术语表版本；存储带 ID 的翻译与对齐数据。
- glossary：每篇文档的术语映射。
- annotations：规范批注 key 和额外的中文选区范围。评论与颜色不以此为真值来源。

相关术语表版本以本块命中的术语子集计算，因此无关术语的编辑不会导致全篇缓存失效。JSON 写入使用临时文件和同路径写入队列。缓存是本地的；跨设备需要各设备拥有翻译缓存，标准 Zotero 批注继续使用 Zotero 自身的同步机制。

## 架构与参考来源

新增模块全部位于 `src/bilingual/`：reader、parser、translation、alignment、annotations、cache、glossary、ui。原插件仅新增启动/卸载调用，以及翻译任务的逐请求 instruction 字段；不会修改共享服务 prompt 来临时请求翻译。

基础：[windingwind/zotero-pdf-translate](https://github.com/windingwind/zotero-pdf-translate)。保留 AGPL-3.0-or-later 许可与上游代码。

参考：[1281300805/zotero-inline-translate](https://github.com/1281300805/zotero-inline-translate)。研究了 readerOverlays.ts 的 PDF 坐标、阅读器窗口身份与批注事件处理，以及 overlayStore.ts 的持久化队列。该项目按句序和字符比例推算目标范围的方式没有用于本实现；这里使用翻译请求的稳定 ID；译文短选区按句段内相对位置近似映射至原文词边界。未移植其覆盖 PDF 页面文字的整套渲染器。

同时核对了本机 Zotero 9.0.6 的 reader.js、annotations.js 与 PDF reader runtime。私有 PDF 接口集中在 pdfIntegration 中进行适配；跨作用域的 getPageData 参数使用 cloneInto。

## 构建与验证

需要 Node.js 22.8+ / npm，使用上游 lockfile：

```sh
npm ci
npm run build
npm run test:bilingual
```

真实 Zotero 集成测试在 Windows PowerShell 中运行：

```powershell
node test/fixtures/build-images.mjs
$env:BILINGUAL_TEST = '1'
$env:BILINGUAL_FIXTURE = 'C:\\absolute\\path\\to\\bert.pdf'
$env:ZOTERO_PLUGIN_ZOTERO_BIN_PATH = 'C:\\Program Files\\Zotero\\zotero.exe'
node node_modules/zotero-plugin-scaffold/bin/zotero-plugin.mjs test --no-watch
```

测试使用独立的 `.scaffold/test/profile` 和 `.scaffold/test/data`，以 headless 模式启动，不使用个人资料库。PDF 样本是公开的 16 页 [BERT 论文](https://arxiv.org/abs/1810.04805)，含双栏、标题、图表、引文；测试自行创建已有标准批注。测试翻译使用确定性的模拟服务，不验证商业服务凭据或真实学术译文质量。

测试范围见 [VALIDATION.md](VALIDATION.md)。

### 2.4.8-bilingual.6：表格预览修复

表格优先在标题下方定位，图示优先在图注上方定位，并尝试另一侧。成功显示表格预览后，表格内拆散的文字及译文保留在“查看表格文字与翻译”展开项中，表下注释继续正常显示。已用问题截图对应论文的第 12 页验证。

### 2.4.8-bilingual.7：两种阅读模式

- 沉浸式阅读：中英对照、仅中文、仅英文；字号 12–28 px、行距 1.4–2.2，设置保存在本机。
- PDF 对照：左侧为原生 Zotero PDF，右侧为可选中文字的分页译文；按原文坐标保留栏宽、标题、图表的空间关系。中文较长时向下排开并延长该页，避免截断和重叠，因此不是逐像素复刻或新生成的译文 PDF。原始图表中的文字保持原样。
- 右侧译文可独立缩放，左右可同步翻页或独立滚动。高亮、下划线和评论保存为原 PDF 的标准 Zotero 批注。手绘使用左侧原 PDF 的原生工具；手绘笔迹不会复制到重排译文上。
- 翻译速度可选 1/2/3 路（默认 2）；优先当前阅读页，每段完成即缓存。服务报错后停止派发，等待在途请求结束再恢复；受服务延迟及限流影响，不保证固定加速倍数。切换阅读模式、字号不重新翻译。
- 术语表对普通服务也生效：按词边界、较长术语优先，在本地固定用户指定译法，引用和公式保持原样。大模型通过现有学术提示词结合上下文使用词表。术语表变更只使涉及词条的段落缓存失效。
- 本次未实现手机端；移动阅读、译文传输和批注双向同步是独立后续工作。

### 2.4.8-bilingual.8：图片去重与文字表格

同页同一位置的重复图注与图片预览去重；原图内容保持不变。带可识别边界、能可靠分列的纯文字表格重建为 HTML 表格，逐单元格翻译，保留列宽、跨列表头、行列顺序与原文坐标。沉浸式和 PDF 对照模式共用这些单元格；译文变长时自动撑开行高，单元格仍可高亮、下划线和评论。复杂、跨页或无法可靠识别结构的表格仍使用原图/原 PDF 查看入口，不猜测单元格。解析缓存版本更新为 5，重新打开文档时自动更新结构。

### 2.4.8-bilingual.9：固定原页版式

PDF 对照模式保留原页面尺寸及正文、图片、表格的坐标，不再因译文变长而推移后续内容或延长纸张。原先从正文中排除的页眉、页脚和页码单独保存并在对照模式按原坐标显示，不送翻译；保留页边水平分隔线。正文和表格译文在原区域内自适应字号，过长译文可能字号较小，可使用译文缩放或切换沉浸式阅读。图片内容不变。沉浸式继续去掉页眉页脚，并允许正文和表格自由伸展。两种模式共享译文缓存及原 PDF 标注。

这仍是可选择文本的 HTML 页面，不是改写 PDF 文件，也不使用整页截图或 OCR。特殊字体、彩色页眉、复杂装饰、旋转文字等不能保证逐像素还原。原文中的结构识别错误仍可能影响布局。缓存版本 9 自动更新页面结构，未变化的正文可复用译文缓存。

### 2.4.8-bilingual.10：单词范围标注

从中文译文选词创建的原文批注按译文与句段的相对位置估算英文范围，再吸附至英文词边界；短选区只标注最近的一个英文词。多词选区可以映射为短语。不同语序下对应仍是近似结果，请核对原 PDF。选择原文时保留精确字符范围。

### 2.4.8-bilingual.11：工具栏和对照分栏

工具栏设置区可收起，记住上次状态；阅读模式改用高对比度主按钮。PDF 对照模式增加可拖动的中间分隔线，也可聚焦后用方向键微调，宽度比例保存在本机。原 PDF 中有 PDF.js 可识别的可点击链接批注时，链接覆盖到的文字和译文对应部分显示蓝色。引用链接文本若翻译后改变，颜色映射按句段字符位置近似计算。仅用蓝色字体绘制、却没有可点击链接批注信息的 PDF 文字无法可靠识别颜色。

### 2.4.8-bilingual.12：对照交互和标注对齐回退

阅读方式切换独立占一行，使用普通控件样式。分隔线的鼠标拖动启用指针捕获，增加键盘微调；比例只在拖动结束后保存。移除 PDF 链接颜色复制功能。为避免字符比例将中文词错误对应到无关英文词，译文侧批注恢复为稳定句段 ID 对齐；单词选区在原 PDF 中对应完整英文句段，界面明确提示这一精度边界。
