# BiRead 保姆级教程：从 GitHub 下载，到 Zotero 双语阅读与标注

**适用版本：BiRead 0.1.2-beta。**本文以 Windows 桌面版 Zotero 为例，按顺序操作即可，不需要懂代码，也不需要注册 BiRead 账号。

> BiRead 仍是测试版。建议先用一篇不重要的论文试用，并保留 Zotero 数据备份。目前实际操作验证环境为 Windows x64 / Zotero 10.0.6；模型一键安装暂不支持 macOS、Linux 和 Windows ARM。手机端尚未实现。

## 先分清三个东西

| 名称 | 用途 | 需要做什么 |
| --- | --- | --- |
| Zotero 桌面程序 | 管理论文、打开 PDF | 先安装 Zotero |
| BiRead 插件（`.xpi`） | 增加双语阅读、翻译和标注界面 | 下载后装进 Zotero |
| 本地对齐模型（可选） | 帮助找到中英文对应词组 | 在插件里点一次“一键安装” |

**全文翻译和词组对齐不是同一件事。**安装模型不会代替翻译服务；只想看译文，可以先不装模型。

## 第一步：准备 Zotero 和一篇 PDF

1. 电脑还没有 Zotero：到 [Zotero 官网下载页](https://www.zotero.org/download/) 安装桌面程序。已有 Zotero 就直接打开。
2. 准备一篇英文 PDF，最好先选篇幅较短、排版简单的论文。
3. 把 PDF 拖进 Zotero 中间的文献列表。已有文献附件的用户跳过这一步。
4. 双击 PDF 附件，确认它在 **Zotero 内置阅读器**中打开，而不是跳到浏览器、Adobe 或其他软件。
5. 用鼠标拖选一句英文。如果能选中文字，就可以继续；如果只能选到整张页面图片，可能是扫描件，BiRead 目前不提供 OCR。

## 第二步：从 GitHub 下载正确的安装包

1. 打开 [BiRead 发布页 Releases](https://github.com/WWeiyiWang/BiRead/releases)。**下载公开附件不需要登录 GitHub。**
2. 找到 **v0.1.2-beta**。以后有新版时，优先看新版的发布说明。
3. 向下找到 **Assets**（附件列表）；如果折叠了，点击展开。
4. 点击 **`BiRead-0.1.2-beta.xpi`** 下载到电脑，通常在“下载”文件夹。

请认准后缀 **`.xpi`**：

- `BiRead-0.1.2-beta.xpi`：这是要安装的插件。
- `Source code (zip)` / `Source code (tar.gz)`：这是源码，普通用户不用下载。
- `SHA256SUMS-0.1.2-beta.txt`：用于核对文件的校验信息，不是安装包。

不要点仓库首页的 **Code → Download ZIP** 来安装。下载后的 XPI **不用解压，也不用双击运行**；下一步从 Zotero 里选择它。不要把源码 ZIP 改后缀冒充 XPI。

## 第三步：把插件装进 Zotero

1. 回到 Zotero。
2. 点击顶部菜单 **工具（Tools）→ 插件（Plugins）**。
3. 在插件管理页找到右上角 **齿轮按钮**。
4. 选择 **从文件安装插件… / Install Plugin From File…**。
5. 找到刚下载的 `BiRead-0.1.2-beta.xpi`，选中并打开。
6. 按 Zotero 的提示完成安装；若要求重启，重启 Zotero。
7. 回到插件列表，确认出现 **BiRead — Bilingual PDF Reader for Zotero**，且处于启用状态。

也可将 XPI 拖到 Zotero 的插件管理窗口安装，参见 [Zotero 官方插件说明](https://www.zotero.org/support/plugins)。

**如果已经装过旧版 BiRead：**仍按上面的步骤安装新版 XPI 即可，不需要先卸载或删除数据。当前测试版请手动更新，不要等待自动更新。

**如果装过 Translate for Zotero：**无需先安装它才能使用 BiRead。两者是独立插件，但当前 beta 阶段不建议同时启用；试用 BiRead 时请先停用上游 Translate for Zotero，避免重复弹窗。BiRead 不会自动迁移它的 API 密钥，需要在 BiRead 中重新配置。

## 第四步：设置正文翻译服务

1. 打开 Zotero 的 **设置**。Windows 通常从 **编辑 → 设置**进入；英文界面可能显示 **Settings / Preferences**。
2. 找到 **翻译 / Translate** 设置页。
3. 在“服务”区域找到 **翻译服务**，选择你能使用的服务。
4. 将源语言设为英文（或自动识别），目标语言设为中文。
5. 若该服务需要密钥或自定义地址，按该服务要求填写；不需要密钥的选项不要随意填入内容。

**第一次建议先用普通翻译模式，不勾选 ACADEMIC MODE。**先确认一段正文能正常翻译，再调整其他设置。

插件不要求单独注册或登录 BiRead，但你选的翻译服务可能需要账号、密钥或付费。Google、Google(API) 等是不同选项；是否可用取决于对应服务、配置和网络，不能保证每个人都能直接使用。不要把 ChatGPT 网页会员当成其他 API 的可用额度。

## 第五步：打开双语阅读

1. 回到 Zotero 内的 PDF 标签页。
2. 找到阅读器上方的 **BILINGUAL** 按钮，点击它。
3. 阅读区域会出现 BiRead 界面，并逐段显示译文。
4. 看不到服务、字号等选项时，点右上角 **显示设置**。
5. 等第一段出现译文后，就可以边读边等待后续内容，不必等整篇完成。

看到“等待翻译…”不一定是出错；先看顶部状态。如果一直没有结果、出现超时或限流提示，按本文最后的故障表处理。

### 选择阅读模式

| 想做什么 | 选择什么 |
| --- | --- |
| 文字更大、阅读更集中 | **沉浸式阅读** |
| 一边看原 PDF，一边看译文 | **PDF 对照** |
| 同时看中英文 | **中英对照** |
| 只看翻译 | **仅中文** |
| 只看原文 | **仅英文** |

在 **阅读方式**一行切换“沉浸式阅读 / PDF 对照”。在设置里调整显示语言、字号、行距等。调好后点 **收起设置**，给正文留出空间。

PDF 对照会保留原 PDF，并尽量让译文保留页面结构、标题和图表位置；不是完美复刻版面。复杂表格、图表或分栏不正常时，用 **OPEN IN PDF** 回原文核对。图片内容不会被翻译。

### 常用按钮对照

| 界面文字 | 用途 |
| --- | --- |
| **PDF** | 返回原 PDF 阅读 |
| **Pause** | 暂停翻译 |
| **Retry / Resume** | 重试或继续翻译 |
| **Glossary** | 设置当前论文的术语表 |
| **Highlight selection** | 高亮所选文字 |
| **Underline selection** | 给所选文字加下划线 |
| **按章节跳转…** | 跳转到识别出的章节 |
| **OPEN IN PDF** | 在原 PDF 中查看相应内容 |

“加速”意味着同时发出更多翻译请求，并不保证一定更快。遇到限流时改回 **稳妥 · 1 路**，稍等后再重试。

## 第六步：一键安装本地词组模型（可选）

想用中英文对应高亮时，建议完成这一步。**Windows x64 用户无需自己装 Python，也无需复制命令。**

1. 在 BiRead 阅读界面点 **显示设置**。
2. 点击 **一键安装本地模型**，不要点旁边的“手动选择模型配置”。
3. 首次联网下载约 **194 MB**，请预留约 **1 GB** 空间，保持 Zotero 打开并等待。
4. 顶部会依次显示下载进度、安装和验证状态。
5. 看到 **“本地模型安装完成并已启用”** 后即可使用。

只需要安装一次。以后打开 Zotero 不必重新操作；重复点击会检查已有环境，正常时不会重新下载。已配置过可用模型的用户也不必强制更换。

安装失败时检查网络和空间，再点一次重试；已下载且校验通过的文件会复用。模型下载需要访问 Python.org、PyPI 和 Hugging Face。详情见 [本地模型一键安装说明](LOCAL_MODEL_ZH.md)。

## 第七步：高亮、划线和添加批注

先确认你要标注的那一段已经有译文。第一次练习建议用 **沉浸式阅读 + 中英对照**。

### 高亮或划线

1. 用鼠标选中一个中文或英文词语，也可以选一个短语。先在同一段内选择，不要跨多个段落。
2. 在选区上右键，菜单会出现在鼠标旁边，选区仍保持可见。
3. 点击 **高亮** 或 **划线**。
4. 看另一侧是否标出了对应词语；首次处理这一段可能需要稍等。

也可以选中文字后使用上方的 **Highlight selection / Underline selection** 按钮。颜色可在设置或标注详情中调整。

**模型是辅助工具，不保证每个词都对应准确。**无法可靠匹配时可能只保留单侧标注；中文单侧标注可能显示“本机译文标注（未同步原 PDF）”，这不是保存失败。

### 添加批注：不用按保存

1. 选中文字 → 右键 **批注**；或者点击已有的高亮，打开下方标注详情。
2. 在输入框写下自己的解释、问题或阅读笔记。
3. 输入后自动保存；看到 **已自动保存** 就可以关闭面板。
4. 关闭后再点开同一个标注，可以查看已保存的内容。

若显示保存失败，请先保留输入并处理提示，不要立即强退 Zotero。批注自动保存与“术语表保存”是两回事，术语表仍需要自己的保存按钮。

## 第八步：对应错了，手动改一次

例如你选了“土壤样本”，英文却没有选中 `soil samples`：

1. 点击这条高亮，打开下方标注详情。
2. 点击 **绑定 / 重新关联词组**。
3. 在原段落中选中正确的英文 `soil samples`。
4. 点击面板中的 **使用英文选区**。
5. 如果中文范围也错了，选中正确中文，再点 **使用中文选区**。
6. 检查面板显示的英文和中文范围，确认正确后点 **确认绑定**。

也可以在对应输入框填写**当前段落中实际存在且唯一出现的文字**，再点击“使用输入”。同一个词出现多次时，用鼠标选中准确位置。

自写释义应填在“批注”里；不能把原文中不存在的一句话当成绑定目标。旧标注也可以用这个流程修正，无需重建所有标注。取消关联操作不会提交本次修改。

## 第九步：让术语译法更统一

1. 先点 **Pause** 暂停翻译，或者等当前翻译完成。
2. 点击 **Glossary**。
3. 每行写一条，使用英文术语、箭头和期望的中文译法，例如：

```text
affordance → 可供性
public space → 公共空间
```

4. 点击 **Save glossary** 保存；需要更新现有译文时点击 **Save & retranslate affected blocks**（保存并重译受影响段落）。

术语表针对当前论文。重新翻译可能改变文字，从而使旧的词组位置失效；已有标注对应异常时，需要重新关联。

## 常见问题：照着排查

| 遇到的问题 | 先做什么 |
| --- | --- |
| GitHub 下载的是 ZIP | 回 Releases → Assets，下载 `.xpi`；不要下载 Source code |
| 提示插件不兼容或安装失败 | 确认文件是完整的 BiRead XPI，记录 Zotero 版本和报错；不要靠改后缀解决 |
| 看不到 BILINGUAL | 确认 BiRead 已启用，PDF 是在 Zotero 内打开；按提示重启后重新打开 PDF |
| 提示 Plugin was disabled | 到工具 → 插件确认 BiRead 状态；启用后重开 PDF，必要时重启 Zotero |
| 译文一直出不来 | 检查所选翻译服务、目标语言、网络及必要的密钥；先关闭 ACADEMIC MODE，再点 Retry / Resume |
| 超时、限流或额度不足 | 先暂停，降低并发；检查服务额度或稍后重试，不要连续反复点击 |
| 模型装好了还是不能翻译正文 | 本地模型只做词组对齐；仍需配置正文翻译服务 |
| 没有一键安装按钮 | 确认使用 0.1.2-beta 或更新版本，展开“显示设置” |
| 模型安装失败 | 检查磁盘、网络及平台，保留顶部报错后重试；其他系统暂不支持一键安装 |
| 中文没有同步到英文或对应错误 | 用“绑定 / 重新关联词组”修正；先确认同一段两侧文本都已显示 |
| 表格、图片或页眉排版不正常 | 回原 PDF 核对；复杂排版仍可能识别不完整 |
| 手机上找不到这些功能 | 当前 BiRead 是桌面插件，未实现手机端 |

## 保存、同步与费用：用之前知道这些就够了

- **无需 BiRead 账号。**普通下载公开 GitHub 附件也不需要 GitHub 账号；创建 Issue 等互动通常需要登录 GitHub。
- **本地模型对齐不调用付费 API。**正文翻译是否收费由所选服务决定；大模型 API 可能按 token 计费。
- **正文翻译会把文字发送给所选服务。**本地词组对齐在电脑上运行，两者要分清。
- **不是所有数据都跟着 Zotero 同步。**词组映射和本机译文标注当前不通过 Zotero 同步；原 PDF 的标准 Zotero 标注则按 Zotero 自身设置处理。换电脑需要重新配置本地模型。
- **升级不需要删缓存。**下载新版 XPI 再安装即可；不要为了升级手动删除 Zotero 数据目录。

## 还是遇到问题？这样反馈最容易定位

到 [BiRead Issues](https://github.com/WWeiyiWang/BiRead/issues) 新建问题，附上：

- 系统：例如 Windows 11 x64。
- Zotero 版本、BiRead 版本。
- 使用的翻译服务名称，是否启用本地模型。
- 操作步骤：选了什么、点了哪个按钮、预期怎样、实际怎样。
- 顶部报错原文或截图；词组错配请同时给出对应的中英文段落（仅限方便公开的内容）。

不要提交 API 密钥、账号令牌或私人论文全文。安装与使用的更多细节见 [使用说明](../biread/BILINGUAL.md)。
