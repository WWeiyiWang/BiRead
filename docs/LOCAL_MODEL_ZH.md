# 本地模型：一键安装（Windows）

从 **BiRead 0.1.2-beta** 起，不用自己安装 Python、复制命令或填写配置文件。

## 只需三步

1. 从 [GitHub Releases](https://github.com/WWeiyiWang/BiRead/releases) 下载 **BiRead-0.1.2-beta.xpi**，在 Zotero 的 **工具 → 插件 → 从文件安装插件** 中更新。
2. 打开论文，进入 **BILINGUAL → 显示设置**，点击 **一键安装本地模型**。
3. 等待页面提示 **本地模型安装完成并已启用**，之后就可以选中中文或英文词语进行高亮、划线或批注。

首次需要联网下载约 **194 MB**，请预留约 **1 GB** 磁盘空间。界面会显示下载进度，插件自动校验文件、解压、生成配置并实际运行模型检查。**只有检查通过才启用**；安装期间仍可阅读。重复点击会检查并复用已经安装的模型，不重复下载。

当前一键安装支持 **Windows x64（64 位 Intel / AMD）**，实测 Zotero 10.0.6；macOS、Linux、Windows ARM 暂不提供一键安装。高级用户仍可使用 **手动选择模型配置**，旧的有效配置也能继续用。

## 安装失败怎么办？

保留界面报错，检查网络和磁盘空间，再点击 **一键安装本地模型**。已完整下载且通过校验的文件会复用，失败的文件重新下载。下载来源为 Python.org、PyPI 和 Hugging Face；网络无法访问其中某个网站时，安装无法完成，不会假装成功。

安装文件位于 Zotero 数据目录下的 `biread-bilingual-v1/alignment-win-x64-v1/`，不安装到系统 Python，也无需管理员权限。没有启动常驻网络服务。不要移动这个目录；换电脑需在新电脑上重新安装。

## 我必须装模型吗？

**不是。**论文翻译、阅读、批注和手动绑定不依赖模型。模型用于根据上下文寻找已有中英文的对应词组，不负责全文翻译。安装后词组对齐在本机完成，不需要模型账号或 API 密钥，也不产生对齐 API 费用；正文翻译服务的联网、收费规则保持不变。

模型仍可能错配，尤其是意译、省略、重复词和过长段落。发现不对，点击标注 → **绑定 / 重新关联词组**，手动选择正确对应文字即可。不能保证每个词都准确对应。

## 已验证的内容

在 Windows / Zotero 10.0.6 中实际点击按钮，完成全新独立运行目录的下载、安装、自动配置和运行检查；重复点击复用已有环境。实际选词验证了英文 `visitors` 对应中文“游客”，以及中文“颜色”对应英文 `colors`。这不代表所有论文和词语都能准确匹配，也不代表已在所有 Windows 电脑上测试。

需要手动配置时，参见 [高级手动配置教程](LOCAL_MODEL_MANUAL_ZH.md)。
