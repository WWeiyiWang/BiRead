# BiRead 0.1.25-beta：公式与完整图表修复验证

验证日期：2026-10-17。解析缓存版本：22。此版本在本地构建，未发布到 GitHub，也未替换用户当前安装。

## 本次改动

- 根据页面坐标和实际分栏证据定位公式、图表；支持不同页面尺寸、非零页面原点和偏离页面中线的栏间距。
- 识别 PDF 黑白图像蒙版、重复蒙版和组合图像；兼容 PDF.js 的分离与合并绘制指令。裁剪文字的路径不再作为可见图形参与图表拼接。
- 保留独立公式、上下标及图片形式的公式；无法映射为 Unicode 的行内符号使用原始 PDF 小图嵌入段落，不猜测符号，也不发给翻译器。
- 支持 Roman、Supplementary、Extended Data 和中文图表编号；相邻双语图注与明确标注的同号子图合并，图注继续参与翻译。
- 跨栏图不会因下方双栏正文或图注被截成半张；有图片和数字表格组成的复合图按同一 Fig 保留。
- 表题在上方或下方均可定位；合并分段绘制的横线，包含一个表号下的完整表格区域。
- 修复部分 PDF 提取器把单词拆进多个伪列的情形；保留正常的双栏阅读次序。
- 排除图表上方的章节文字、下划线与分离的罗马章节编号；限制图注续行吞入后续正文。
- 无法确定图表归属时触发布局质量检查并保留原页，不显示破碎预览或把乱码公式作为正文。
- 解析缓存由 21 升为 22；重新打开 BiRead 时重建解析结果，不删除原 PDF、标注或词汇表。

## 验证边界与已知问题

这是通用规则和质量回退的改进，不是所有未知 PDF 均可正确识别的证明。没有按文件名、作者或论文题目定制识别分支。

- 个别紧邻正文的图像裁剪边缘仍可能带有少量相邻文字残影；本次抽查的中文 Fig. 8 顶部仍存在这一小范围问题。
- 无文本的扫描页未做 OCR，因此保留原页，不自动翻译；跨页续图、无图号图像及任意异常排版仍需要更广泛验证。
- 集成测试采用受控译文检查占位符与图片排版，没有调用在线翻译服务；不能据此评价 Google 等服务的翻译质量。
- 尚未把本包安装进用户当前 Zotero 配置做实际使用验收。完整矩形匹配和图片成功加载不等于每个像素的图表边界都正确，已在上述抽查中区分。

## 安装与校验

在 Zotero 插件管理器选择“从文件安装插件”，安装 `BiRead-0.1.25-beta.xpi` 后重启，再打开 BiRead。无需手动清空标注或词汇表。
