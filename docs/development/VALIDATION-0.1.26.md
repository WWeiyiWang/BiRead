# BiRead 0.1.26-beta：行内公式与连续阅读验证

验证日期：2026-10-18。解析缓存版本 23，译文缓存键版本 4。本包已在本地构建，未发布、未安装进用户的 Zotero 配置。

## 修复范围

- 在段落切分之前，根据实际基线、字体尺寸、字符坐标及阅读顺序重建行内公式。分数的分母、延迟输出的上下标与所在句子一起处理，避免变成独立正文卡片。
- 将识别出的行内数学对象作为原 PDF 图片嵌入正文和译文；变量不再单独送给翻译器。完整的独立公式和图表仍沿用原图展示，图注继续翻译。
- 同一字符只归属一个公式区域；裁剪范围内已经显示的标点不重复输出。保留降部字符，仅收紧无降部拉丁字符及数字的空白字体边界，减少带入下一行文字。
- 保留正常单词、小字号词语和列间边界，避免把普通正文当作下标，或为连接公式而跨栏拼接。
- 单独的 A/I 句首不再作为章节编号；带分隔符的 A.、II.、数字章节及多层标题继续识别。
- 普通机器翻译优先按完整句段请求，用受保护标记保留公式、引文及术语位置。响应必须恰好保留每个标记一次；标记丢失、重复或未知时，退回保守拼接。网络失败仍正常报错，不静默追加请求。
- 加强未重建数学碎片的质量检查：孤立罗马字母、缺少操作数的向量不能作为正常正文通过。无法可靠重建的页面保留原页。公式编号和已有行内数学对象不应误触发该检查。
- 升级解析与译文缓存键，使旧的分段和碎片译文失效；不要求删除 PDF、标注或词汇表。

这些规则没有依据论文文件名、标题或作者设置专用分支。

## 验证边界

- 样本回归通过不代表任意 PDF 均能正确识别。复杂列表里的多行公式仍有未恢复的案例；此版选择保留该页原版，尚未实现该页连续翻译。
- 机器翻译标记恢复使用受控返回值测试；中英排版截图中的中文是人工准备的测试译文，没有调用在线 Google 服务，不据此宣称实际翻译质量已验收。
- 尚未在用户正在使用的 Zotero 配置中安装实测；浏览器集成检查与真实 Zotero 使用环境仍有差别。
- 无文本扫描页没有新增 OCR。跨页续图、无图号图像和任意异常排版仍需继续扩大验证。
- 原图预览成功加载与坐标检查不能证明每个裁剪像素都正确；复杂数学字体或紧邻文字时仍可能出现边缘残影。
